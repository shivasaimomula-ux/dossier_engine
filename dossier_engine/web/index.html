🌿 Dossier Engine

Honest Clinical & Regulatory Evidence Platform checking…

What this platform does

It ingests a supplement formulation and produces an evidence map — not a polished marketing dossier. Its defining rule:

The engine never invents a value, citation, concentration, or mechanism. When a source returns nothing, the field is stamped “NOT ESTABLISHED / insufficient data,” and that status propagates all the way to the final document.

The problem it solves

Retrieval systems (and LLMs) tend to over-claim: they hang many pathways and cellular mechanisms on a single PubMed ID, present in-vitro or animal findings as if they support human use, and sometimes cite papers that don’t say what’s claimed. This platform puts a second, independent model — Claude — between retrieval and the final report to authenticate every claim against the real paper.

Grounded
Every finding carries a real PubMed citation or is marked a gap.
Tiered
Evidence is ranked NONE → Preclinical → Human, and language can’t exceed the tier.
Authenticated
Claude reads the real abstract and rejects claims the paper doesn’t support.
Regulatory-aware
Disease/treatment phrasing is flagged regardless of evidence.

Informational tooling — not medical advice or a regulatory certification. A qualified professional must review the output before any use.

How it works — six agents + an authenticator

An orchestrator runs five specialists over the formulation; a Claude authentication layer verifies the evidence before it’s graded.

The authentication layer

For every claim–PMID pair, Claude fetches the real abstract directly from PubMed and answers: is the PMID real? do the paper’s actual findings support this claim? what is the true evidence level (in-vitro / animal / human / RCT)? is this the paper’s primary finding or a peripheral mention? It rejects mismatches, downgrades inflated tiers, and detects a single PMID reused across many unrelated claims.

Pipeline

per ingredient: PubMed search → retraction check → MeSH relevance gate │ (on-purpose papers) ▼ Claude authenticator (fetch REAL abstract → verify) │ │ │ AUTHENTICATED REJECTED UNVERIFIED │ │ │ graded dropped kept + flagged ▼ grade tiers → compiled evidence sheet

With no API key set, the authenticator is bypassed and the pipeline falls back to the deterministic MeSH relevance gate.
